\section{Casos de uso}

Un caso de uso describe una interacción completa entre un actor (en este sistema, el usuario) y el sistema para alcanzar un objetivo concreto, como iniciar la simulación o definir la vecindad \cite{ingenieria_1}. La figura \ref{fig:uml_ucd} resume los casos de uso del simulador, agrupados en controles de simulación, configuración del autómata celular, interacción con el espacio celular y entrenamiento del autómata celular neuronal; cada uno se especifica en la sección \ref{sec:especificaciones}.

\section{Diccionario}

El diccionario enumera y codifica los elementos de la interfaz con los que interactúa el usuario, de modo que las especificaciones de los casos de uso y los diagramas de secuencia puedan referirse a ellos sin ambigüedad. Cada elemento tiene un código formado por un prefijo y un número consecutivo: UI para las interfaces gráficas (los paneles o pestañas del simulador), BTN para los botones, SLD para los deslizadores (\textit{sliders}), IN para las entradas de datos que proporciona el usuario, OUT para las salidas que muestra el sistema y MSG para los mensajes de error o de aviso.

\subsection{Interfaces gráficas}
\begin{itemize}
	\item \NewUI{control_ui}{Control}: Elemento que contiene los botones de control sobre la simulación del espacio celular.
	\item \NewUI{simulacion_ui}{Simulación}: Elemento que contiene la cuadrícula del espacio celular y muestra la evolución del autómata celular.
	\item \NewUI{configuracion_ui}{Configuración}: Elemento que permite realizar la configuración de la vecindad, condición de frontera, estados y función de transición.
	\item \NewUI{training_ui}{Entrenamiento}: Contiene la personalización del entrenamiento del autómata celular neuronal.
\end{itemize}
