\begin{abstract}
	\noindent \textit{Resumen} --- \textbf{En esta investigación se define un autómata celular neuronal como método para extraer la regla que rige un sistema complejo mediante el entrenamiento de una red neuronal para inferir el patrón de comportamiento desde un conjunto de datos de entrenamiento.}
	
	\vspace{0.8em}
	\noindent \textit{Palabras clave} --- \textbf{Autómatas celulares, Autómatas celulares neuronales, redes neuronales, sistemas complejos, simulación.}
