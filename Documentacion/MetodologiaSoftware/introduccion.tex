El desarrollo de software, al igual que muchos procesos, tiene un ciclo de vida que determina las diferentes etapas por las que tiene que pasar para ser desarrollado. Para poder llevar este proceso de forma organizada, se utilizan metodologías de desarrollo de software las cuales coleccionan técnicas y métodos organizativos para diseñar soluciones informáticas \cite{software_1}.

En el capitulo anterior fue descrita la metodología de investigación utilizada, en este nuevo capitulo nos adentramos en definir la metodología para el desarrollo de software, utilizado esencialmente para el simulador. Ademas, se define la arquitectura del sistema y los casos de uso bajo un enfoque de investigación.
