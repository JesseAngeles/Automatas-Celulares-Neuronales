\section{Análisis de sistema}

\subsection{Reglas de negocio}

\begin{enumerate}[label*=RN\arabic*]
	\item El estado de una celda en el tiempo $t + 1$ depende unicamente de su estado actual y de los estados de sus vecinos.
	\item Para iniciar la simulación es necesario que el conjunto de estados, la topología de la vecindad, la condición de frontera y la función de transición hayan sido definidas. 
	\item Cuando la simulación esta en curso no se puede cambiar el conjunto de estados, la topología de la vecindad ni la función de transición.
	\item El usuario puede manipular el estado de una célula y la condición de frontera en tiempo de ejecución.
	\item Los datos importados deben de cumplir con el formato definido por el sistema para garantizar su correcta interpretación.
	\item Los datos exportados deben conservar el mismo formato que los datos importados.
	\item El usuario puede pausar, detener, reanudar o retroceder la simulación sin perdida de información. 
	\item Solo se permite una simulación activa por sesión.
\end{enumerate}

\subsection{Requerimientos}

\subsubsection{Requerimientos funcionales}

\begin{enumerate}[label*=RF\arabic*]
	\item El sistema debe mostrar una cuadricula regular y finita que represente el espacio celular. 
	\item El sistema debe permitir al usuario establecer el conjunto de estados, la topología de la vecindad y la condición de frontera en el espacio celular.
	\item El sistema debe permitir al usuario interactuar con el espacio celular, asignando o modificando los estados de las células.
	\item El sistema debe permitir al usuario importar y exportar evoluciones del espacio celular.
	\item El sistema debe permitir al usuario evolucionar el espacio celular en un solo paso, o de forma continua estableciendo la velocidad de actualización según las capacidades computacionales.
	\item El sistema debe permitir al usuario definir la función de transición.
	\begin{comment}
		
	\item El sistema debe permitir al usuario configurar el entrenamiento de una ANN seleccionando hiperparametros, la evolución.
	\item El sistema debe entrenar una ANN dadas las configuraciones del usuario y generar su función de transición local.
	\item El sistema debe de registrar métricas de rendimiento, medidas de tendencia central y medidas de dispersión.
	\end{comment}
	
\end{enumerate}

\subsubsection{Requerimientos no funcionales}

\begin{enumerate}[label*=RNF\arabic*]
	\item El sistema debe poder ejecutar en Fedora 42 sin requerir modificaciones en el código fuente.
	\item El sistema debe ser capaz de procesar al menos $10000$ celdas o registros por segundo utilizando una GPU NVIDIA RTX 5080.
	\item El sistema debe garantizar disponibilidad continua durante la ejecución, sin fallos o interrupciones criticas.
	\item La interfaz del sistema debe ser intuitiva, con mensajes entendibles e iconografía contemporánea.
\end{enumerate}

\subsubsection{Requerimientos de hardware y software}

Configuración recomendada:

\begin{itemize}
	\item \textbf{Procesador:} Intel Core i9-14900K × 32 núcleos.
	\item \textbf{GPU:} NVIDIA GeForce RTX 5080.
	\item \textbf{Sistema operativo:} Fedora Linux 42 (Workstation Edition).
	\item \textbf{Entorno de escritorio:} GNOME 48.
	\item \textbf{Sistema de ventaneo:} Wayland. 
\end{itemize}
