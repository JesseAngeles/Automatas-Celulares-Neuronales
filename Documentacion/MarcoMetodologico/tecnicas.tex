\section{Técnicas e instrumentos de recolección de datos}

La recolección de datos se realiza a partir de las simulaciones computacionales realizadas. Dado que se trata de enfoque cuantitativo, se es necesario usar técnicas de observación como encuestas, sino procedimientos de registro automatizado para su posterior análisis numérico. 

\subsection{Técnicas de recolección de datos}

\begin{itemize}
	\item Simulación computacional: Ejecución del modelo del automata celular baja diferentes configuraciones de vecindad, estados y arquitectura de ANN.
	
	\item Registro automatico de datos: Datos generados por la simulación. Como el historial evolutivo, patrones, y métricas de estabilidad, error y desempeño.
	
	\item Análisis estadístico: Se aplican métricas cuantitativas que permiten comparar configuraciones para evaluar la efectividad del modelo. Métricas como precisión, convergencia, tasa de error y comportamiento temporal de los patrones.
\end{itemize}

\subsection{Instrumentos de recolección de datos}

Se consideran los siguientes instrumentos para obtener y analizar los datos:
\begin{itemize}
	\item Simulador desarrollado: Herramienta computacional implementada en Python que permite ejecutar y visualizar el comportamiento de los autómatas celulares neuronales.
	
	\item Códigos de registro y procesamiento: Conjunto de programas auxiliares que capturan las métricas numéricas de cada simulación y almacenadas en archivos.
	
	\item Herramientas de análisis estadístico y visualización: Librerías y herramientas que permiten obtener representaciones graficas con los datos obtenidos. 
\end{itemize}
