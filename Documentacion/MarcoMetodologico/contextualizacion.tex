\section{Contextualización de la tecnología}

El desarrollo de un simulador de sistemas complejos mediante autómatas celulares neuronales implica la integración de múltiples tecnologías, seleccionadas estratégicamente para satisfacer los requerimientos funcionales y técnicos del proyecto. Entre estos se incluye el diseño de una interfaz grafica de usuario intuitiva, la simulación de CA bidimensionales con diferentes estados, vecindades y funciones de transición, la personalización de condiciones iniciales y el entrenamiento de sistemas para la replicación de comportamientos brindados por el usuario.

La elección de estas tecnologías responde a criterios de compatibilidad, escalabilidad, facilidad de implementación y disposición de herramientas especificas para el procesamiento de datos e inteligencia artificial. 

Con el fin de proporcionar una visión clara y compresiva de las bases técnicas del proyecto, en este capitulo se presentan tanto el área de estudio , elementos clave para orientar el desarrollo del simulador y validarlo, así como los fundamentos y el contexto de las tecnologías utilizadas, así como los entornos de trabajo que hacen posible este trabajo. 

\subsection{Fundamentos y contexto de las tecnologías}

Un lenguaje de programación es una herramienta que permite el desarrollo de software y programas para computadora. Son empleados para diseñar programas encargados de definir el comportamiento físico y lógico de una computadora \cite{uapaLenguajes}.

Debido a que la elección del entorno y lenguaje de programación resulta crítica para el éxito de cualquier proyecto, es importante considerar las metas y alcances del proyecto, puesto que no todos los lenguajes son óptimos para resolver ciertos tipos de problemas \cite{clickpandaEntorno}.

Entre los factores clave para la elección de un lenguaje de programación se encuentra la escalabilidad y el rendimiento, el costo de mantenimiento, la compatibilidad y el sistema de herramientas, entre otras \cite{clickpandaEntorno}.

Es por esto que, como lenguaje de programación se decidió utilizar C++/CUDA, para el núcleo de simulación y cálculos pesados en paralelo; y Python, para la interfaz, visualización, control de simulación y diseño de redes neuronales. 

A continuación se presentan las definiciones pertinentes de los lenguaje de programación, frameworks y librerías utilizadas para el desarrollo de la aplicación móvil.

\subsubsection{C++}

C++ es un lenguaje de programación compilado y multiparadigma desarrollado como una extensión de C \cite{c_1}. Se considera un lenguaje de bajo nivel ya que permite manipular directamente la memoria, lo que lo convierte en un lenguaje muy poderoso. Es orientado a objetos, permite la creación de clases y objetos y es ampliamente utilizado para aplicaciones que requieren un alto rendimiento.

Es utilizado en motores de videojuegos, software de sistemas, aplicaciones en tiempo real, simulaciones científicas y calculo numérico \cite{c_2}. para esta investigación, se utilizaran las siguiente bibliotecas de C++:

\begin{itemize}
	\item \textbf{Eigen:} biblioteca para álgebra lineal y manipulación eficiente de matrices y vectores \cite{eigen}.
	\item \textbf{tiny-dnn:} librería para redes neuronales ligeras, permitiendo definir la función de transición de los autómatas celulares neuronales \cite{tiny_dnn}.
	\item \textbf{pybind11:} facilita la integración de código C++ con Python, permitiendo exponer funciones y clases para análisis y visualización \cite{pybind}.
	\item \textbf{HDF5 C++ API:} para almacenar y leer grandes volúmenes de datos de simulación de manera eficiente \cite{hdf5}.
\end{itemize}

\subsubsection{CUDA}

CUDA es una plataforma de computación paralela y un modelo de programación desarrollado por NVIDIA que permite utilizar la GPU para cálculos de propósito general. Se emplea para acelerar operaciones matemáticas y simulaciones que requieren gran cantidad de procesamiento paralelo, como el entrenamiento de redes neuronales \cite{cuda}.


\subsubsection{Python}

De acuerdo con la página oficial de la documentación de Pyhton \cite{pythonTutorial}, es un lenguaje de programación potente y fácil de aprender. Tiene estructuras de datos de alto nivel, sintaxis simple y elegante, un tipado dinámico, naturaleza interpretada, etc. 

Además de ser gratuito, se puede integrar bien en todos los equipos y sistemas. En adición a esto, \cite{awsPython}, señala que en los beneficios que Python incluye se encuentran los siguientes:

\begin{itemize}
	\item Fácil lectura y comprensión de los programas.
	\item Mayor productividad al escribir un programa con menos líneas de código que en comparación con muchos otros lenguajes de programación.
	\item Se puede usar fácilmente con otros lenguajes de programación.
	\item Soporte rápido de la comunidad.
	\item Se puede trasladar a través de diferentes sistemas operativos de computadora.
\end{itemize}

En adición a lo anterior, cuenta con una amplia colección de librerías y frameworks diseñados para tareas que resultaron muy convenientes en el desarrollo de la aplicación móvil. Se detallan tanto librerías como frameworks a continuación.


\begin{itemize}
	
	\item \textbf{Os:}
	es una librería que provee funcionalidades dependientes del sistema operativo como abrir un archivo, manipular rutas, leer archivos, crear archivos temporales, etc. \cite{pythonOS}.
	
	\item\textbf{NumPY} es una librería de Python especializada en el cálculo numérico y el análisis de datos. Es ideal para el manejo de grandes volúmenes de datos \cite{alfaro_numpy}.
	
	Puede hacer operaciones hasta 50 veces mas rápido que las listas normales usando una objeto llamado arreglo que permite representaciones colecciones de datos en varias dimensiones \cite{alfaro_numpy}.
	
	\item \textbf{CuPy} es una biblioteca de matrices de código abierto para la computación acelerada por GPU con Python. Utiliza bibliotecas del CUDA Toolkit para hacer un uso completo de la arquitectura GPU. Es compatible con NumPy y permite definir núcleos CUDA personalizados \cite{cupy}. 
	
	\item\textbf{PyTorch} es una biblioteca de tensores optimizada para el aprendizaje profundo utilizando GPU y CPU \cite{pytorch_1}. Se emplea para crear redes neuronales, combinando la biblioteca de ML de Torch con una API de alto nivel basada en Python. 
	
	Es uno de los marcos de ML destinados a comunidades académicas y de investigación por su flexibilidad y fácil uso, además de admitir una amplia variedad de estructuras de redes neuronales \cite{pytorch_2}.
	
	\item \textbf{PyQt5 / PySide6} son herramientas que permiten usar Python como un lenguaje alternativo de desarrollo de aplicaciones a C++ en todas las plataformas soportadas \cite{qt_1}. PyQt5 también puede integrarse en aplicaciones basadas en C++ para permitir a los usuarios de dichas aplicaciones configurar o mejorar la funcionalidad de las mismas, mientras que PySide6 ofrece compatibilidad oficial con las bibliotecas Qt desarrolladas por The Qt Company \cite{qt_2}.
	
	\item \textbf{h5py} es una librería que proporciona una interfaz entre Python y el formato de almacenamiento de datos jerárquico HDF5 (Hierarchical Data Format). Este formato permite manejar grandes volúmenes de datos de manera eficiente, organizándolos en estructuras tipo árbol con grupos y conjuntos de datos. Con h5py es posible almacenar, leer y modificar datos numéricos de gran tamaño directamente desde Python, lo cual resulta especialmente útil en simulaciones científicas que generan grandes matrices multidimensionales \cite{h5py}.
	
	\item \textbf{pybind11} es una biblioteca de C++ diseñada para exponer tipos y funciones de C++ en Python y viceversa, facilitando la creación de extensiones de Python basadas en código C++ \cite{pybind}. Puede generar enlaces entre ambos lenguajes de manera compacta, eficiente y con un código más simple, posibilitando así integrar cálculos de alto rendimiento escritos en C++ dentro de entornos Python.
	
	\item\textbf{Pandas} es una librería especializada en el manejo y análisis de estructuras de datos. Entre sus principales características, \cite{alfaro_pandas} menciona:
	
	\begin{itemize}
		\item Define nuevas estructuras de datos basadas en los arrays de la librería NumPy.
		\item Permite leer y escribir fácilmente ficheros en formato CSV, Excel y bases de datos SQL.
		\item Permite acceder a los datos mediante índices o nombres para filas y columnas.
		\item Ofrece métodos para reordenar, dividir y combinar conjuntos de datos.
	\end{itemize}
	
	\item\textbf{Matplotlib} De acuerdo con \cite{alferez_matplotlib}, Matplotlib es una librería de Pyhton especializada en la creación de gráficos en dos dimensiones.
	
	Además, mencionan que permite crear y personalizar los gráficos más comunes, entre los que se encuentran:
	
	\begin{itemize}
		\item Diagramas de barras.
		\item Histograma.
		\item Diagramas de sectores.
		\item Diagramas de caja y bigotes.
	\end{itemize}
	
	\item\textbf{Scikit-learn} es una librería que cuenta con algoritmos de clasificación, regresión, clustering, y reducción de dimensionalidad, etc. Es compatible con otras librerías de Python \cite{mds_scikitlearn}.
	
	Entre sus principales características \cite{itop_scikitlearn}, destaca las siguientes:
	
	\begin{itemize}
		\item Clustering.
		\item Ensemble methods.
		\item Validación cruzada.
		\item Varios conjuntos de datos o datasets de prueba.
		\item Reducción de la dimensionalidad.
		\item Optimización o ajuste de hiperparámetros.
		\item Feature selection.
	\end{itemize}
	
\end{itemize}

\subsection{Entornos de trabajo}

El desarrollo del presente proyecto requiere de un entorno colaborativo, flexible y bien estructurado que facilite tanto la construcción como la validación de los distintos componentes del sistema. Para ello, se han seleccionado diversas plataformas que permiten organizar tareas, escribir y probar código, almacenar datos, así como documentar y presentar avances de manera clara y profesional.

\subsubsection{Plataformas de desarrollo}

Con el fin de cubrir las distintas etapas del proyecto, desde la implementación hasta la comunicación de resultados, se utilizaron múltiples herramientas que favorecen la eficiencia y el trabajo en equipo. Las siguientes plataformas han sido clave para mantener un flujo de trabajo continuo y bien coordinado.

\begin{itemize}	
	\item\textbf{Visual Studio Code} Comúnmente conocido como VSCode, es un editor de código gratuito, de código abierto y compatible con múltiples sistemas operativos. Fue creado por Microsoft, empresa con amplia trayectoria en el desarrollo de entornos integrados (IDE), lo que se refleja en la eficiencia y funcionalidad que ofrece esta herramienta, muy valorada por la comunidad de desarrolladores \cite{cimas2024vscode}.
	
	Aunque su nombre puede sugerir una relación directa con Visual Studio, en realidad VSCode es una aplicación independiente, construida desde cero con tecnologías diferentes. Mientras Visual Studio se orienta principalmente a tecnologías propias de Microsoft, VSCode destaca por su flexibilidad y capacidad de adaptarse a prácticamente cualquier lenguaje de programación \cite{garcia2024vscode}.
	
	\item\textbf{Github} Es una plataforma basada en la nube donde puedes almacenar, compartir, trabajar y versionar junto con otros usuarios para escribir código \cite{github2025about}. En adición a lo anterior, también permite realizar lo siguiente:
	
	\begin{itemize}
		\item Presentar o compartir el trabajo.
		\item Seguir y administrar los cambios en el código a lo largo del tiempo.
		\item Dejar que otros usuarios revisen el código y realicen sugerencias para mejorarlo.
		\item Colaborar en un proyecto compartido, sin preocuparse de que los cambios afectarán al trabajo de los colaboradores antes de que esté listo para integrarlos.
	\end{itemize}
	
	El versionamiento, una de las características fundamentales de GitHub, es posible gracias al software de código abierto Git, en el que se basa GitHub \cite{github2025about}.
	
	\item\textbf{Canva}	Lanzada en 2013, Canva es una herramienta de diseño y publicación online que tiene como misión poner el poder del diseño al alcance de todo el mundo, para que cualquier persona pueda diseñar lo que quiera y publicar donde quiera \cite{canva2025about}.
	
	\item\textbf{TexStudio}	TeXstudio es un entorno de escritura integrado para la creación de documentos LaTeX. Cuenta con numerosas características como resaltado de sintaxis, visor integrado, comprobación de referencias y varios asistentes. TeXstudio es de código abierto y está disponible para todos los principales sistemas operativos \cite{texstudio}.
	
\end{itemize}
